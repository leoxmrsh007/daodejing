## 数据格式规范

### 章节注释格式

```json
{
  "chapter": 1,
  "original": "道可道，非常道...",
  "modern_chinese": "可以用语言表述的道...",
  "注释家ID_note": "注释内容...",
  "english_译者ID": "English translation..."
}
```

### 注释内容要求

1. **准确性**：基于权威注本，引用需标注来源
2. **简洁性**：每条注释控制在 50-200 字
3. **教育性**：解释核心概念，帮助理解原文
4. **上下文**：考虑与全章/全书的关系
