📖 平台概述

道德经多版本对照学习平台是一个基于 Flask 的 Web 应用，支持多版本经典古籍的对照学习、搜索、TTS 服务和 AI 创新功能。

⚡ 核心功能

  • 多经典管理（道德经、庄子等）
  • 章节内容获取与搜索
  • 疑难字标注与注解
  • TTS（文本转语音）服务代理
  • AI 创新功能（知识图谱、语义考古等）

🔧 技术栈

  • 后端：Flask + Python 3.9+
  • 前端：Vanilla JavaScript + Bootstrap 5
  • 架构：模块化设计（services/, routes/, utils/）
  • 部署：支持 Flask 动态部署和静态站点生成

🔒 安全特性

  • 所有输入都经过验证
  • 搜索端点有速率限制
  • XSS 防护
  • CORS 配置支持
