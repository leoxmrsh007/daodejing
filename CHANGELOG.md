# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Code quality tools integration (Flake8, MyPy, Black, isort)
- Pre-commit hooks configuration
- CI/CD pipeline with GitHub Actions
- Test suite with 86% coverage
- OpenAPI/Swagger documentation
- MIT LICENSE file
- CHANGELOG.md
- CONTRIBUTING.md

### Changed
- Reformatted code with Black
- Sorted imports with isort
- Fixed Flake8 warnings

## [1.2.0] - 2026-01-29

### Added
- Multi-classic support (Daodejing + Zhuangzi)
- 11 commentary versions for Daodejing
- 6 English translation versions
- Ancient text variants (Mawangdui Silk Texts, Guodian Chu Slips)
- AI-powered features:
  - Knowledge Graph visualization
  - Semantic Archaeology analysis
  - Cross-Civilization Dialogue
  - Virtual Commentator
- TTS support (Fish Audio + Edge TTS)
- PWA support
- Dark mode
- Responsive design
- Static site generation

### Changed
- Improved data structure for multi-version support
- Enhanced frontend UI with Bootstrap 5

## [1.1.0] - 2026-01-15

### Added
- Qing Dynasty commentaries (Li Hanxu, Huang Yuanji, Wei Yuan)
- Additional English translators (Waley, Lin Yutang, Mitchell)
- Background music player (Guqin, Bianzhong)
- Advanced features:
  - Idiom dictionary
  - Bookmark and favorites
  - Reading notes
  - Advanced search
- Reading progress tracking
- Copy to clipboard functionality
- Quote cards generation

### Changed
- Enhanced chapter navigation
- Improved text display

## [1.0.0] - 2026-01-01

### Added
- Initial release
- Basic Daodejing content (81 chapters)
- Core commentaries (Wang Bi, He Shanggong, Wang Fuzhi, Hanshan Deqing)
- English translations (D.C. Lau, Henricks, Addiss & Lombardo)
- Basic web interface
- Search functionality
- Vercel deployment support
